# 西安观鸟图鉴 · 使用说明

用浏览器打开项目根目录的 `index.html` 即可使用。约15 MB，160种鸟的文字和参考照片都已嵌入，离线可查阅；只有打开外部资料链接时需要联网。手机请使用支持JavaScript的浏览器，有些聊天软件的文件预览不会运行筛选功能。

页面顶部及筛选区均有“使用指南”入口，可随时查看同类说明。

## 两种找鸟方式

### 我到了某个观鸟地，想知道这里可能有哪些鸟

1. 在 **“我在这里”** 选择地点，例如“新渭沙湿地公园”。不选地点时，浏览全部160种。
2. 在 **“月份”** 选择出行月份，例如“9月”；不选月份时，查看全年候选。
3. 如果就在芦苇边观察，可继续将 **“生境”** 设为“芦苇”，只保留同时满足这些条件的鸟。
4. 想只看资料明确提到过的鸟，勾选 **“仅看有地点记录的鸟”**。该选项必须先选择地点。

地点下方显示观察区域、推荐季节、候选数量和资料链接。它是人工选择的地点筛选，不读取GPS；最近一次选择会在当前浏览器中保存。

### 我看到一只不认识的鸟，想根据外形找名字

直接使用搜索框，不必先知道鸟名，也不必先选地点。

- **颜色、部位或体态：** 如 `红嘴`、`蓝`、`黑白`、`长尾`、`黄斑`。
- **行为：** 如 `悬停`、`潜水`。
- **多个特征：** 如 `红嘴 蓝`，中间用空格分开，表示两词都必须出现在该鸟的资料中。当前图鉴中该例会找到红嘴蓝鹊。
- **已知名字：** 也能输入中文鸟名、学名或收录的英文参考名，如 `翠鸟`、`Alcedo atthis`。

这是**文字关键词匹配**，搜索范围包括鸟名、学名、英文参考名、辨认特点、介绍、生境及外观变化。它不会自动分析照片，也不会自动理解一整段自然语言。英文不区分大小写。

建议从一个最确定的短词开始，再逐步加条件。`长尾` 和 `尾长` 不会自动视为同义词；没结果时可换一种说法或减少关键词。文字可能提到雌鸟、幼鸟、冬羽，甚至“没有某特征”的描述，所以搜索结果仍需结合照片和说明核实。

## 每个筛选项怎么用

| 界面选项 | 作用 | 示例／注意 |
|---|---|---|
| **我在这里** | 从本图鉴中筛出该地点的候选鸟 | 18处观鸟地；选“全部地点 · 图鉴总览”可取消地点限制 |
| **仅看有地点记录的鸟** | 排除只按生境推定的候选 | 有资料记录不等于今天一定能见到；某地暂无逐种记录时可能显示0种 |
| **搜索框** | 按鸟名、学名、特征与行为等文字查找 | `红嘴 蓝` 为同时匹配；不必先选地点 |
| **类群** | 按图鉴分组缩小范围 | 如“雁鸭与天鹅”“猛禽与鸮”；不是每一组都对应严格的分类学阶元 |
| **月份** | 只保留推荐观察窗口包含该月的鸟 | “全年总览”不限月份；月份不明确的偶见鸟可能不进入具体月份结果 |
| **生境** | 按鸟活动的环境筛选 | 湖泊、浅水、河流、芦苇、树林、灌丛、草地、农田、建筑等；生境不等于具体公园 |
| **学习顺序** | 选择“先认识／再留意／进阶辨认／少见记录” | “先认识”对应36种入门鸟；标签不是出现概率，也不是保护级别 |
| **只看已见** | 在当前条件下只显示自己标记过的鸟 | 可以与地点、月份、搜索等叠加；再次点击取消此限制 |

**普通筛选条件取交集。** 例如“新渭沙 + 9月 + 芦苇 + 一个关键词”，显示的是同时满足全部条件的鸟。条件越多，结果通常越少。

## 快捷按钮会做什么

| 按钮 | 结果 |
|---|---|
| **先认身边的鸟** | 选择“先认识”的36种入门鸟，再与已选地点、地点记录限制取交集，因此现场结果可能少于36种 |
| **9—10月秋迁** | 保留推荐窗口包含9月或10月任一月的鸟；也会包含全年留鸟，并非只显示迁徙鸟 |
| **冬季水鸟** | 保留水鸟相关类群中，推荐窗口包含11、12、1、2月任一月的鸟 |

前三个快捷按钮会**保留地点及“仅看有地点记录”的选择**，但会重设搜索词、月份、类群、生境、学习顺序和“只看已见”开关，再应用对应快捷条件。再次点击当前已选快捷按钮，可退出该模式。

手动修改搜索词、月份、类群、生境或学习顺序，会结束“秋迁／冬季水鸟”等快捷季节模式。若需要精确组合，比如“某地12月的雁鸭”，直接使用地点、月份和类群三个下拉框即可。

## 怎样理解结果

- **“有地点记录”**：链接资料曾明确提及这只鸟出现在该地点或注明的片区；可能是历史记录、迁徙经过或少见到访。
- **“按生境可留意”**：根据当地环境整理的候选，尚未核实本点的明确记录。
- 有地点记录的鸟优先排列；其后参考学习顺序。
- **“找到N种”**是当前全部筛选条件下的结果数，**“已展开M种”**是已经显示的卡片数。默认展开24种，点击底部“继续查看”可逐批浏览余下结果。
- 筛选始终覆盖文件里全部160种，不只检索已经展开的卡片。

找不到时，先减少关键词，或者把月份、生境、类群改回“全部”；也可取消“仅看有地点记录”或“只看已见”。仍不确定时点击 **“重置”**，恢复全部160种总览。

**重置只清除筛选条件和最近地点选择，不删除已见标记，也不清空对照栏。**

## 图片、说明与并排对照

- 点击任意鸟的照片可放大，查看照片说明、作者、许可及原文件链接。按“关闭 ×”或键盘 `Esc` 返回。
- 展开卡片中的 **“雌雄季节差异 · 易混淆 · 资料”**，查看雌雄／幼成／季节变化、相似鸟种、地点入选依据及来源。
- 在两张或三张卡片上点击 **“加入对照”**，再点击屏幕底部的 **“打开对照”**。再次点击卡片按钮可移除单种，“清空”可清除全部对照项。
- 顶部 **“易混淆对照”** 可跳到9组预设对照，如三种白鹭、两种常见野鸭。预设对照是学习材料，不受当前筛选结果限制。

一张照片只代表某个个体的一种状态，不能覆盖该鸟所有性别、年龄和季节外观。先看轮廓和嘴脚，再结合羽色分区与行为判断。

## 已见标记与CSV导出

在卡片上点击 **“标记已见”**，再次点击可取消。已见信息保存在当前浏览器本地，不会上传，也不会在设备之间自动同步。更换浏览器、清理站点数据或改用另一份本地文件时，可能读不到原来的记录。

**“导出已见清单”会导出全部已标记鸟，而不是只导出当前筛选后可见的鸟。** CSV包含鸟名、学名、建议观察月份、标记时间；标记时间不是实际观测时间。尚无已见标记时，按钮会提示先标记。

若浏览器禁止本地保存，本次打开期间仍可标记和导出，关闭页面后可能无法保留。CSV目前用于备份和整理，图鉴未提供导入功能。

## 信息可能不准确，欢迎交流

本图鉴的信息可能存在错误、遗漏或过时之处，包括鸟种辨识、图片对应、出现月份与地点记录。欢迎在本项目 GitHub 仓库的 **Issues → New issue** 中选择“纠错、补充与交流”，提交问题、补充记录或讨论辨识依据。

尽量注明相关鸟名／地点、需要核对的描述、你的判断及参考链接或照片。观察记录可提供月份和大致区域；不确定也欢迎讨论，我们会在核实后逐步完善图鉴。请避免填写私人联系方式或敏感巢址。

## 范围与资料

本图鉴覆盖西安及西咸新区18处常见观鸟地与相邻平原生境；160种／实用分类条目不是全市或各公园的穷尽名录，也不覆盖秦岭高海拔鸟类。候选名单与推荐月份不是实时鸟讯；空结果不等于现场没有鸟。

全部参考照片来自Wikimedia Commons，逐张署名和许可见图鉴及 `图片来源与许可.md`。照片不默认拍摄于西安，部分是圈养参考个体。地点资料与按生境推定分开保存，不把区域数据库记录冒充为精确公园记录。

主要维护文件：`data/species.tsv`（名录）、`data/descriptions.tsv`（辨识内容）、`data/places.json`（地点与记录依据）、`scripts/template.html`（界面）。构建和测试命令见项目README。
