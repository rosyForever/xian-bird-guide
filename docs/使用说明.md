# 西安观鸟图鉴 · 使用说明

主文件：`index.html`。直接用现代浏览器打开，单文件约15 MB，文字与160种鸟的参考照片全部嵌入，离线可用，无需安装依赖。

## 内容

160种／实用分类条目，约2.3万字辨识内容。每种有中文名、学名、真实参考照片、体长、推荐月份、生境、三个辨认线索、一段介绍、雌雄与季节差异、易混淆提示、物种和图片来源。

以西安及西咸新区18处常见观鸟地及相邻平原生境为范围。不是西安市全部野生鸟类的穷尽名录，不把秦岭高海拔鸟类和所有迷鸟都塞入日常出行清单。月份为寻找窗口，非逐点逐月调查结论。

## 使用

- 先在“我在这里”选择18处观鸟地之一，再按月份、类群、生境和关键词组合筛选。
- 每条候选标记为“有地点记录”或“按生境可留意”；勾选“仅看有地点记录的鸟”可排除推定项。最近地点保存在当前浏览器，不读取GPS。
- 先点击“先认身边的鸟”，从36种入门鸟开始。
- 点照片放大；点击卡片“加入对照”，选2—3种后打开对照。页面底部还有9组预设对照。
- “标记已见”保存在当前浏览器本地，导出按钮可保存CSV。导出时间为标记时间，不替代实际观测日期。
- 默认展开24种，向下点击继续加载。所有160种均已保存在文件内，筛选覆盖全部条目。
- 手机需通过支持JavaScript的浏览器打开；有些聊天软件的文件预览不会运行交互功能。

## 图片与证据

全部照片来自Wikimedia Commons，作者和许可逐张保留在图鉴及 `图片来源与许可.md`。照片仅用于物种外观参考，不默认摄于西安，部分为圈养参考个体；同一鸟种雌雄、幼成与不同季节可能差异极大。

出现线索结合区域管理机构、鸟类监测和媒体资料，并检索GBIF经度108.60—109.10、纬度34.15—34.50范围内2010年至2026-09-22的记录。原始记录有采样偏差，不等于出现概率；不同名称与分类处理不能直接相加。黄雀暂列区域扩展参考，未在此次矩形检索中检出，不据此声称任何一个点位有稳定记录。

## 文件

- `index.html`：可独立携带、离线打开的成品。
- `图片来源与许可.md`：逐图署名及许可。
- `data/species.tsv`：名录、月份、生境及学习顺序。
- `data/descriptions.tsv`：逐种中文辨识内容。
- `data/places.json`：18处地点、候选生境与地点记录来源。
- `data/guide.json`：含来源和图片署名的结构化资料，不含内嵌图片。
- `data/sources/`：查询到的物种资料与Commons原始许可信息。
- `data/gbif_facets.json`：区域鸟类名称记录数检索快照。
- `assets/`：160张参考照片。
- `scripts/build_guide.py`、`scripts/template.html`：离线图鉴生成程序与模板；生成需要Python和Pillow。
- `qa/`：配图联系表、电脑和手机截图、交互检查结果。
